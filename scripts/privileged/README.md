# Привилегированная часть: только проектный шаблон

`nftables-design.template.nft` — намеренно неисполняемый эскиз. В нём нет
реальных адресов, интерфейсов, команд применения либо очистки. Он не является
конфигурацией firewall.

Перед переносом логики в изолированный стенд владелец EVE-NG вручную одобряет
конкретные interface, namespace, адреса, порты, исходное состояние и rollback.
Шаблон запрещено применять копированием или запускать от root. В каталоге нет
команд `nft`, `wg`, `ip`, `sudo`, start/stop.
